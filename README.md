| Case | What it shows |
|---|---|
| [User journey: lightweight foldable scooter](01-user-journey/) | User research with 36 interviews, turned into a journey map and product-definition priorities. |
| [Overseas User Knowledge Hub](02-overseas-user-knowledge-hub/) | A tool that links community posts, orders and product models, with a brief PRD and a working demo. |
